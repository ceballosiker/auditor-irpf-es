# Política de seguridad

## Versiones soportadas

| Versión | Soporte                   |
| ------- | ------------------------- |
| 0.x     | Sí (en desarrollo activo) |
| < 0.1   | No                        |

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad **no abras un issue público**. Envía un correo a **iker@acuratio.com** con:

- Pasos para reproducir.
- Impacto estimado.
- Versión afectada (commit o tag).

Te responderé en un plazo razonable (objetivo: 7 días) con confirmación de recepción y un plan de mitigación.
